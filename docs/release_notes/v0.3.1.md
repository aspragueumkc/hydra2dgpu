# HYDRA2DGPU v0.3.1 — QGIS Plugin Repository Acceptance Release

This release resolves all security findings from the QGIS Python Plugins
Repository review so HYDRA2DGPU can be approved for listing in the
official QGIS plugin repository.

## Security fixes

- **Eliminated all bare `except: pass` blocks** — every exception swallow
  now logs the error instead of failing silently
- **Widget Inspector no longer shells out to `grep`** — replaced with a
  pure-Python file scan so widget names never touch a command line
- **Hardened all `subprocess` calls** — fixed argument lists only (no
  shell), script paths validated to resolve inside the plugin directory,
  with justifications documented for the security review
- **Restricted network access to HTTPS** — the backend installer's GitHub
  API probe now enforces an https-only scheme guard
- **Replaced `assert` with explicit runtime error checks** so validation
  survives optimized bytecode compilation

## Packaging

- **`LICENSE` (MIT) now bundled in the plugin zip**
- **Author email updated** in plugin metadata
- Marked `experimental` in metadata for the repository review

All 0.3.0 functionality is preserved — GPU-accelerated 2D SWE solver,
new spatial reconstruction schemes, first-launch wheel installer, dual
QGIS 3.28+/4.x support.
